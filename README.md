# M2-Projet-ENEDIS
### Projet Python / Machine Learning (M2 SISE 2025)  

## À propos du projet

**GreenTech Solutions** est une société de services très très très réelle et pas du tout inventée spécialisée dans le développement d’applications à impact environnemental.  
Dans le cadre du partenariat avec **Enedis**, nous avons pour mission de créer une **application web interactive** permettant à des particuliers :  

- d’évaluer la **classe de Diagnostic de Performance Énergétique (DPE)** d’un logement 🏠,  
- d’estimer la **consommation énergétique associée** ⚡,  
- et de **visualiser les données** à travers des **indicateurs, cartes et graphiques dynamiques** 📊.
