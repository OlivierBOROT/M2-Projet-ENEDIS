# 🌱 GreenTech Solutions 🌱
### Projet Python / Machine Learning (M2 SISE 2025)  

## À propos du projet

**GreenTech Solutions** est une société de services très très très réelle et pas du tout inventée spécialisée dans le développement d’applications à impact environnemental.  
Dans le cadre du partenariat avec **Enedis**, nous avons pour mission de créer une **application web interactive** permettant à des particuliers :  

- d’évaluer la **classe de Diagnostic de Performance Énergétique (DPE)** d’un logement 🏠,  
- d’estimer la **consommation énergétique associée** ⚡,  
- et de **visualiser les données** à travers des **indicateurs, cartes et graphiques dynamiques** 📊.

---

### Navigation dans l’application  

Pour naviguer dans l’application, utilisez la barre de menu en haut de l’écran. Les sections disponibles sont :  

**Accueil**  

**Contexte**  
- Données : découvrez les sources et la description des jeux de données utilisés pour ce projet.  
- Rapports : consultez les rapports techniques, utilisateurs et synthétiques réalisés dans le cadre du projet.  

**Visualisations**  
- Graphs : visualisez les données à travers une sélection de graphiques et d’indicateurs pertinents.  
- Cartographie : explorez les données sous un angle spatial pour découvrir de nouvelles perspectives.  

**Prédiction**  
- Testez nos modèles pour prédire la **classe DPE** ou estimer la **consommation énergétique** de votre logement.
